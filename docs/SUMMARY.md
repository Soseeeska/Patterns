# Сводка: композиты баланса и заметки по стратегии (ES, TPO 30m)

Всё, что посчитано в этом проекте, в одном месте. Данные: ES, 30-минутные бары RTH, 16.12.2020 – 09.11.2026 (1470 полных дней). Цифры — из скриптов в `scripts/`, пороги — в `config.yaml`.

**Главное коротко**
1. Зоны прошлых композитов (VAH/VAL/POC/HVN) на 30m в целом ведут себя как случайные уровни такой же ширины. Это проверено тремя правилами композита и тремя определениями реакции.
2. Из заметок по данным подтверждаются: ширина IB → характер дня, ложный выход за IB → разворот, место открытия → где сформируется value, inside/outside-день → следующий день.
3. Не подтверждаются на ES RTH 30m: место открытия → ширина/потенциал дня, hidden levels, направление дня после гэпа.
4. Для проверки входов с минутки, типов открытия по Далтону и hidden levels нужны **минутные данные**; для сравнения с вашими графиками — **ETH-выгрузка**.

## 2. Типы дней по Далтону (откалибровано по вашим замечаниям)

| Тип | Правило | % дней |
|---|---|---|
| Normal Variation | выход за IB (>15% IB) в одну сторону, не Trend | 55.2 |
| Double Distribution | выход в одну сторону + внутренний тонкий разрыв (строки ≤2 TPO) ≥4 тиков и ≥10% диапазона | 15.8 |
| Neutral Extreme / Center | выход в обе стороны; close в 25–75% диапазона → Center | 10.6 / 6.1 |
| Normal | без выхода за IB | 5.9 |
| Trend | выход в одну сторону, диапазон >2×IB, close в крайних 15%, **вытянутый** профиль (VA ≥45% диапазона, ≤9 TPO в строке) | 4.0 |
| Non-trend | без выхода, диапазон <0.6 среднего | 2.4 |

Правки по вашим проверкам: тренд — только вытянутый профиль без «пуза»; разрыв DD считается по строкам с ≤2 TPO (на 30m быстрый переход оставляет 2 TPO); дни без выхода — Normal.

## 4. Как проверялись зоны: фальш-зоны

Каждый вывод сравнивается с **фальш-зонами**: те же композиты, все уровни сдвинуты вместе на ±1–3 ширины VA (20 прогонов). Если реальное значение внутри разброса фальш-зон — у уровня нет своего эффекта. В последней версии фальш-уровень не ближе 8 тиков к любому реальному VAH/VAL/POC. При 20 прогонах около 10% срезов выходят за разброс случайно.

## 5. Результаты по зонам композитов

### 5.1. Дневной исход касания (v1 и v2)
- Принятие (2 периода за уровнем): v1 — 45.6% против 45.7% у фальш; v2 — 45.4% против 45.7%.
- «Первое касание VAH реже принимается» (v1: 31.8% против 43.6%, n=63) при v2 исчезло (39.2% против 39.7%) — был шум.
- Типы дней в дни касаний: больше Double Distribution (21.5% против 15.8% по всем дням), но у фальш-зон столько же. Касаются уровней просто широкие дни.

### 5.2. Вход в композит и close в POC (ваше правило)
Только входы снаружи: VAH сверху, VAL снизу. Принятие = close дня в POC (±2 тика) или за ним.

| Горизонт | Принятие | Отторжение | Фальш (принятие) |
|---|---|---|---|
| День входа | 28.2% | 71.8% | 27.3% |
| День входа + следующий | 46.1% | 53.9% | 46.4% |

- До POC внутри дня доходит 51.7% (за 2 дня — 68.9%); в 23.4% входов дошли до POC, но закрылись обратно.
- 61% принятий за 2 дня — в сам день входа.
- Исключение: в Trend-дни принятие 57.8% против 49.3% у фальш (n=147).

### 5.3. Внутридневная реакция с флипом (30m)
Зона — поддержка/сопротивление по стороне предыдущего close. Пробой = 2 свечи подряд закрылись за зоной → флип. Удержание = свеча целиком на исходной стороне. Одно закрытие с возвратом — ложный пробой.

| Зона | Держит, реальные | Держит, фальш |
|---|---|---|
| VAH | 43.6% | 44.8% |
| VAL | 45.0% | 45.8% |
| POC | 44.9% | 45.6% |
| HVN-полоса (≥70% от max TPO вокруг POC) | 58.4% | 58.8% |

- HVN держит чаще из-за ширины полосы, а не из-за того, что это HVN.
- Отход ≥16 тиков после касания — ~70% и у реальных, и у фальш.
- Слабые отличия: 4-й+ тест VAH держит хуже (35.5% против 45.4%); сопротивление чуть лучше фона, поддержка чуть хуже.

**Вывод по зонам:** на 30m-барах эффект зон композита не виден. Это не доказывает, что его нет на минутке: реакцию, которую вы ловите при входе с 1m, 30m-бар не видит.

## 6. Заметки по стратегии → что показали данные

| Идея из заметок | Как проверено | Результат |
|---|---|---|
| **Expansion potential по месту открытия** (balance / disbalance in range / full disbalance) | Диапазон дня, выход за IB, ход от open | ✗ Диапазон 0.90–0.92× среднего во всех трёх; сильный ход (≥1 среднего) ~24–26% везде; двусторонний ход не чаще вне диапазона |
| Место открытия → «ищет ли цена новый баланс» | Перекрытие VA с прошлым днём, возврат в VA | ✓ Перекрытие VA: 74% / 53% / 30%; возврат в прошлое VA: 100% / 81% / 47%; close вне прошлого VA: 68% / 79% / 86% |
| Open Drive | Грубо по периоду A (open у края A, цена не вернулась) | ~ OD даёт более направленный день (ход 0.83–1.04 против 0.65–0.69). Самый широкий — OD из value (1.07×), n≈50 |
| Направление после открытия вне VA | Close дальше от VA, чем open | ✗ 50/50 |
| «Открылись в балансе → берём POC», растёт при принятии | Касание POC прошлого дня | ~ 81% против 39% при открытии вне VA (принят A — 88.5%, отторгнут — 68.4%), но при одинаковом расстоянии open→POC разница почти пропадает — дело в расстоянии |
| Rejection/Acceptance в A | Close A внутри/вне VA прошлого дня | ~ Влияет на POC (выше), на ширину дня — нет |
| **IB как подсказка диапазона** | IB к среднему за 20 дней | ✓ Узкий IB: день 0.66×, выход в обе стороны 26.5%, без выхода 2.5%. Широкий IB: день 1.32×, в обе стороны 8.2%, без выхода 18.9% |
| **Фейл экстеншн → разворот** | Выход за IB ≥2 п., потом период закрылся внутри IB | ✓ До противоположного края IB 28.9%; ложный выход вверх при узком IB — 42.9%, вниз при широком — 17.6% |
| Последний принт M + гэп | M по ходу/против гэпа | ~ Гэп внутри диапазона закрывается 66–70%, true gap 39–49% (чаще, если M шёл по ходу гэпа: 48.6% против 38.6%); направление дня — 50/50 |
| Смена ротации периодом | Период закрылся за диапазоном всех прошлых | ~ Следующий период подтверждает 65–79%, день закрывается за уровнем 57–69% (без базы — описательно) |
| **Value стабильнее цены** (миграция) | Миграция вчера → сегодня | ✓ После inside-дня value уходит целиком выше/ниже в 30%/30%; после outside — выше лишь 12.4% (база 27.3%), inside в 2.5 раза чаще (n≈90). Обычная миграция почти не продолжается (30% против 27%) |
| Правило 80% | Открытие вне VA, 2 периода close внутри VA | ~ До другого края VA 56.6% (вне VA в диапазоне) и 43.9% (вне диапазона), не 80%; база не посчитана |
| **Hidden levels** (VAH/VAL/POC, прошитые single print) | Первый тест по правилу флипа | ✗ Держит 44.5%; обычный уровень 42.2%, случайный single print рядом 44.9% — работает зона single prints, не уровень |
| Poor high/low, хвосты | Строки на краю профиля | ✗ На 30m хвост есть почти всегда, poor high/low почти никогда — нужны бары мельче |
| FP/Entry (дельта, объём, футпринт) | — | Не проверялось: нужны минутные данные с объёмом и дельтой |

✓ — подтверждается, ~ — частично или без базы, ✗ — не отличается от фона.
