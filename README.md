# Patterns — TPO-профили, композиты и зоны ES

Исследование того, как цена ES работает с уровнями рыночного профиля (Dalton): дневные TPO-профили,
композиты балансов, HVN-зоны, внутридневная переоценка по 30m. Работа завершена; код хранится как
**референс**: модули `tpo/` и скрипты `scripts/` можно брать в другие проекты.

- `SPEC.md` — журнал исследования: определения, все проверки и их цифры, в порядке, в котором они делались.
- `config.yaml` — все пороги; код читает числа только оттуда.

## Данные

| Файл | Что | Период |
|---|---|---|
| `data/ES_30m_RTH.csv` | ESZ6, 30m-бары RTH 08:30–15:00 CT (13 периодов) | 2020-12-16 – 2026-11-09 |
| `data/ES_30m_ETH.csv` | ESZ6, 30m-бары полной сессии Globex 17:00–16:00 CT (46 периодов) | 2023-07-13 – 2026-11-12 |

Формат: без заголовка, `YYYYMMDD HHMMSS,open,high,low,close,volume`, время — начало бара по Europe/Berlin.
Выгрузка не склеена: back-adjust делает `tpo/rolls.py` (контракт меняется в понедельник перед роллом в 15:00 CT;
на общих барах RTH и ETH после склейки совпадают до тика). Инструменты в конфиге: `ES` (RTH) и `ES_ETH`
(ETH+RTH; используется только как бары для взаимодействий — профили и зоны всегда по RTH).

## Установка и проверка

```bash
pip install -r requirements.txt
python -m pytest -q tests          # 43 теста
```

Все скрипты запускаются из корня: `python -m scripts.<имя> [аргументы]`. Результаты пишутся в `output/`
(в git не попадает).

## Принципы проверки

- **Без подглядывания вперёд.** Зона доступна со следующего дня после формирования; метрики зоны считаются по истории строго до дня, на который она используется.
- **Фальш-зоны (placebo).** Каждый эффект сравнивается с теми же расчётами на зонах, сдвинутых на 1–3 ширины. Отличие засчитывается, только если оно выходит за разброс фальш-прогонов.
- **Проверка на новых данных.** Закономерности ищутся до 2025-01-01 и подтверждаются после (`day_context.split_date`).

## Главные выводы

1. **Зоны сами по себе не дают преимущества.** Композиты, HVN-зоны, первородные, подогнанные по телам, классы поддержка / сопротивление / проторговка, скрытые уровни, «сильные» и подтверждённые зоны — удержание, отторжения, остановки экстремумов дня и формирование POC у реальных зон такие же, как у сдвинутых случайных. Карта зон покрывает ~95% цен окна, поэтому «реакция от зоны» на истории есть почти всегда.
2. **Реакция свечи важнее места.** Хвост-отторжение на первом баре теста поднимает удержание с ~40% до ~70% (противоположным хвостом — до ~85%), но так же и у случайных уровней.
3. **Единственное устойчивое отличие зон:** отторжения обратно в диапазон / VA прошлого дня чаще начинаются прямо от зоны композита (≈36% против ≈21% у случайных). На дальнейшую отработку (дойдёт ли до POC прошлого дня) это не влияет.
4. **Локальный контекст работает и держится на новых данных:** open внутри вчерашнего VA → POC вчера ~80%, при принятии в A ~88%; долгосрочные тейлы держат экстремум вдвое чаще краткосрочных; узкий IB почти всегда расширяется; «кто обновляет принты» по периодам — продолжение ~80–87%. Модели по периодам: AUC 0.75–0.86 вне выборки; зоны к ним ничего не добавляют.

Подробные цифры по каждой проверке — в `SPEC.md`.
